# Melodix 🎹

**Melodix** est un générateur d'instrumentales MIDI orienté création : une référence musicale, un style et une ambiance deviennent une nouvelle composition MIDI éditable.

## Prototype actuel

- import d'une référence audio
- BPM, mesures, complexité et seed
- génération locale de **Drums / Bass / Chords / Melody / Counter melody**
- téléchargement individuel des fichiers `.mid`
- compatible avec FL Studio, Ableton, Reaper et autres DAW

> La référence sert actuellement de contexte créatif. Le prototype ne copie pas ses notes et son analyse audio est encore simplifiée.

## Utilisation

Ouvre `index.html` dans un navigateur ou déploie le dépôt avec GitHub Pages.
